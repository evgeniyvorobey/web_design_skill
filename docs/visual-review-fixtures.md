# Visual Review Fixtures Index

Synthetic text fixtures that stand in for a screenshot or rendered page, used to calibrate Mode D reviews. Each fixture describes a specific web page in enough detail to review (viewport specs, hierarchy, components, typography, color/state, interaction states), then states the `## Expected critique`, the `## Prohibited critique` (claims a reviewer must not make from text alone), `## Severity expectations` (Nielsen 0–4), and a `## Rubric score expectation`.

These are **synthetic fixtures only**, not real product screenshots. In live reviews, apply the same evidence discipline: qualify visual claims when no screenshot or rendered URL is provided.
