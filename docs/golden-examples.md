# Golden Examples Index

Compact 4/5-style calibration examples for taste and domain fit across the most common web surfaces. Each file has a `## Prompt`, a `## Golden output`, and `## Design-quality notes`. They are calibration targets, not full structural worked examples (those live at the repo `examples/` root).

Use these when a request needs stronger taste, domain fit, or a reference for what "good" looks like on web.

| Area | File |
|------|------|
| Marketing landing | [marketing-landing](../examples/golden/marketing-landing.md) |
| Ecommerce PDP + checkout | [ecommerce-pdp-checkout](../examples/golden/ecommerce-pdp-checkout.md) |
| Content article | [content-article](../examples/golden/content-article.md) |
| Docs / dev portal | [docs-portal](../examples/golden/docs-portal.md) |
| Web-app dashboard | [webapp-dashboard](../examples/golden/webapp-dashboard.md) |
| Web form | [web-form](../examples/golden/web-form.md) |
| Settings / account | [settings-account](../examples/golden/settings-account.md) |

These examples target 4/5 on the rubric in [`design-quality-rubric.md`](design-quality-rubric.md). They show the marketing-vs-web-app spectrum: marketing landing and content article earn expressive editorial craft; web-app dashboard, web form, and settings earn density and task efficiency.
