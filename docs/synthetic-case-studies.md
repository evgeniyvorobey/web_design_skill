# Synthetic Case Studies Index

Synthetic bad-to-good calibration cases across web domains and modes. Each file shows a `## Prompt`, a plausible `## Weak response`, `## Why this is weak`, a stronger `## Strong response` (4/5 target), `## Why this is stronger`, and `## Regression checks`.

These are **synthetic fixtures for calibration, not validation against a real product** and not real usability data. Use them during maintenance, calibration, or quality-sensitive drafting to compare weak vs strong answer shapes.
